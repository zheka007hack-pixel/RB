# RB Monitor

Система мониторинга респауна рейд-боссов в реальном времени.

## Что умеет

- **Карта боссов** — интерактивная карта с маркерами, фильтрами по уровню и типам
- **Таймеры респауна** — автоматический расчёт статуса (DEAD / RESPAWNING / ALIVE)
- **Мониторинг** — рейд-лидер видит, какие игроки и каких боссов наблюдают в игре, распределение «глаз» по карте
- **Таблица боссов** — сводка с таймерами, сортировка, история изменений
- **RBAC** — роли (Admin / Leader / Member / Newbie), управление пользователями и ролями
- **Провайдеры данных** — подключаемые источники базы боссов (rb.savhead.com, mw2.wiki)

## Провайдеры данных

База боссов наполняется из внешних источников через систему провайдеров. Каждый провайдер — это независимый модуль в `scripts/providers/<name>/`.

**Как переключить источник:**

1. В `scripts/fetch-bosses.ts` и `scripts/import-bosses.ts` изменить `PROVIDER` на нужный (`'savhead'` или `'mw2wiki'`):
   ```ts
   const PROVIDER: ProviderName = 'mw2wiki'; // ← меняется здесь
   ```
2. Скачать/обновить данные:
   ```bash
   pnpm exec tsx scripts/fetch-bosses.ts
   ```
3. Импортировать в БД:
   ```bash
   pnpm exec tsx scripts/import-bosses.ts
   ```

**Проверка перед переключением (dry-run):**

В каждом скрипте есть константа `DRY_RUN`. Установите `DRY_RUN = true` — скрипт сделает реальные запросы, покажет что бы записал, но не тронет файлы и БД. Для `fetch-bosses` действует лимит `DRY_RUN_LIMIT = 3`.

**Загрузка mw2.wiki через браузер:**

Если прямые HTTP-запросы к mw2.wiki блокируются, установите Chromium Playwright и запустите загрузку с флагом `--browser`:

```bash
pnpm exec playwright install chromium
pnpm exec tsx scripts/fetch-bosses.ts --provider mw2wiki --browser
```

Откроется отдельный видимый Chromium Playwright. Системный Chrome и его профиль не используются. После загрузки импортируйте созданный кэш обычным способом.

**Добавление нового провайдера:**
1. Создать папку `scripts/providers/<name>/` с `provider.ts`, `constants.ts`
2. Класс провайдера наследует `BaseProvider` из `scripts/providers/base-provider.ts`
3. Зарегистрировать в `scripts/providers/index.ts`
